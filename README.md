# ISMS 課程課後測驗網站

**教育訓練類別：** ISMS專業課程教育訓練
**課程講師：** 羅宇倫 Allan Lo

學員參加實體或線上課程後，到本網站做課後測驗。

1. 選擇課程，填寫**公司名稱、單位、姓名、職稱、E-mail**、**實際上課日期**和參加方式（實體／線上）。
2. 作答。全部題目都作答後才能交卷。
3. 成績達 **70 分**（可設定）就算通過：
   - **通過**：產生結業證書 PDF 供下載。PDF 第一頁是證書，後面附上測驗題目、學員作答、正確解答和說明／依據。
   - **未通過**：顯示成績，請學員**重新上課或重新閱讀教材**後再測驗，也可以直接重新測驗。未通過時不顯示解答。

## 課程與題庫

| 代碼 | 課程名稱 | 時數 | 題型 | 配分 |
|---|---|---|---|---|
| C01 | ISO 27001標準簡介 | 3 小時 | 是非 10 題 | 每題 10 分 |
| C02 | 資產盤點、風險評鑑及風險改善訓練 | 3 小時 | 是非 10 ＋ 選擇 5 | 6／8 分 |
| C03 | 營運持續運作管理訓練 | 3 小時 | 是非 10 ＋ 選擇 5 | 6／8 分 |
| C04 | 內部稽核觀念與技巧訓練 | 3 小時 | 是非 10 ＋ 選擇 5 | 6／8 分 |

題庫在 `js/questions.js`，可以直接修改題目、答案、配分、說明和課程時數（`hours`），也可以新增課程。

## 設定（`js/config.js`）

| 項目 | 說明 |
|---|---|
| `category` | 教育訓練類別 |
| `instructor` | 課程講師（印在證書上） |
| `signature` | 講師簽名圖檔，預設 `img/signature.png`（透明背景 PNG）；留空則不顯示 |
| `passScore` | 及格分數，預設 70 |
| `certPrefix` | 證書編號前綴，編號格式為 `ISMS-C04-20261003-A02A1F` |
| `recordEndpoint` | 選用。測驗紀錄回傳網址，見下方「測驗紀錄」 |

## 部署（GitHub Pages）

這是純靜態網站，不需要伺服器或資料庫。

1. 到 GitHub repo 的 **Settings → Pages**。
2. Source 選 **Deploy from a branch**，Branch 選要發布的分支，資料夾選 `/ (root)`，然後儲存。
3. 幾分鐘後網站會出現在 `https://<帳號>.github.io/<repo>/`。

在本機預覽：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 嵌入 Google Sites

在 Google Sites 選 **插入 → 嵌入 → 依網址**，貼上 GitHub Pages 網址即可，建議把嵌入框拉高一些。

Google Sites 會把嵌入的網頁放在受限制的 iframe 中，瀏覽器原生的確認視窗、列印和直接下載都會被封鎖。本網站已做了以下處理：

- 交卷、放棄測驗的確認改用頁內對話框，不使用 `confirm()`。
- 嵌入時隱藏「列印」按鈕。產生 PDF 後會顯示「在新分頁開啟 PDF」連結，學員可以在新分頁儲存或列印。
- 頁尾會顯示「在新視窗開啟測驗網站」連結，萬一嵌入環境有其他限制，學員可以改到獨立視窗作答。

## 測驗紀錄（選用，建議啟用）

本網站預設**不保存**學員資料，證書只在學員自己的瀏覽器產生。如果需要集中保存教育訓練紀錄，可以把結果寫進 Google 試算表（例如作為 ISO/IEC 27001 7.2 適任性的證據）：

1. 新建一份 Google 試算表，選 **擴充功能 → Apps Script**。
2. 把 `apps-script/Code.gs` 的內容貼上並儲存。
3. 選 **部署 → 新增部署作業**，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 存取權：**任何人**
4. 複製部署後的網址（`https://script.google.com/macros/s/.../exec`），貼到 `js/config.js` 的 `recordEndpoint`。

啟用後，每次交卷（通過或未通過）都會寫入一筆紀錄，欄位包含：時間、課程、課程時數、公司、單位、姓名、職稱、E-mail、實際上課日期、參加方式、成績、結果、證書編號和作答內容。

> **個資提醒：** 啟用紀錄回傳就會蒐集個人資料（姓名、E-mail 等）。建議在網站或課程說明中加上蒐集目的告知，並依貴公司的個資管理程序管理該試算表的存取權限和保存期限。

## 限制

- 純靜態網站的題目答案寫在前端程式裡，懂技術的人可以從原始碼看到答案。本網站適合用在教育訓練的課後評量；如果用於高風險考試，應改為由伺服器端計分。
- 學員在瀏覽器內按下載證書時產生 PDF，PDF 元件（`js/vendor/`）放在本 repo 內，不需要連外部 CDN。萬一下載失敗，可以改用「列印／另存 PDF」。
